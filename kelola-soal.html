Import Soal

Tempel soal sesuai format di bawah (soal dipisah baris kosong). Format bebas juga didukung: rapat tanpa enter, nomor "Pertanyaan 1?"/"No.3"/"1.", opsi "A."/"A)"/"(A)", jawaban "Jawaban: A"/"Jawaban = A"/"Kunci: A"/"Answer: A". Kalimat pembuka seperti "Berikut adalah..." otomatis diabaikan. Opsi maksimal 6 (A-F); A-D wajib, E/F opsional dan harus kontigu (jangan isi F kalau E kosong). Untuk soal esai tambahkan baris "Jenis: Esai" (tanpa pilihan A-D). Blok kode pakai pembatas ``` di tiap sisinya.

Topik ini dipakai untuk semua soal, atau tulis baris "Topik: Nama" di tiap soal untuk pengecualian.

Format yang dikenali:

Pertanyaan 1?
A. Pilihan A
B. Pilihan B
C. Pilihan C
D. Pilihan D
E. Pilihan E (opsional)
F. Pilihan F (opsional)
Jawaban: B
Topik: Nama Topik (opsional)

Pertanyaan 2?
A. ...
B. ...
C. ...
D. ...
Jawaban: C

Tuliskan output dari kode ini:
```python
print("Hello")
```
